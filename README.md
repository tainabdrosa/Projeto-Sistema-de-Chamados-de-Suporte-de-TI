Sistema de Chamados de Suporte de TI

Sobre o projeto:
O Sistema de Chamados de Suporte de TI, é um projeto acadêmico desenvolvido com o objetivo de facilitar o registro, a organização e o acompanhamento de solicitações de suporte técnico.

A proposta é permitir que usuários registrem problemas ou solicitações relacionadas à Tecnologia da Informação, enquanto a equipe de suporte pode acompanhar e atualizar o andamento dos chamados.

## 🎯 Objetivo do projeto

O principal objetivo é desenvolver uma solução para organizar as demandas de suporte de TI, permitindo:

* Cadastro e registro de chamados;
* Classificação por categoria e prioridade;
* Acompanhamento do status dos chamados;
* Atualização das solicitações;
* Consulta do histórico de atendimentos.

O projeto busca representar uma situação comum no ambiente profissional de TI e aplicar, de forma prática, conhecimentos adquiridos durante o curso.

Tecnologias utilizadas:

HTML— estrutura das páginas;
CSS — estilização e organização da interface;
JavaScript— funcionalidades e interações;
Git— controle de versão;
GitHub — armazenamento e documentação do projeto.

As tecnologias poderão ser atualizadas conforme a evolução do projeto e dos conhecimentos adquiridos durante o curso.
